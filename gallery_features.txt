=========================================
RUDRA NEXUS - IMAGE GALLERY FEATURE SHEET
=========================================

1. CURATED & FEATURED FEED (EXPLORE)
   - Showcases premium curated "Featured" assets for community inspiration.
   - Seeded shuffle randomization logic ensures dynamic layouts per cycle.
   - Live likes counts map dynamically displays backend database-backed social counts for featured items.

2. PERSONAL LIBRARY & GALLERY
   - Keeps track of all assets created, uploaded, or saved by the logged-in user.
   - Clean Pinterest-style bento grid layout with customizable aspect ratios (1:1 Square, 16:9 Landscape, 9:16 Portrait, or Staggered heights).
   - Supports image uploads via file selection or interactive drag-and-drop.

3. PERSISTENT SAVE & LIKE SYSTEM
   - Liking an image bookmarks it in the database for 5 days.
   - Optimistic UI state updates ensure the heart icon fills red and the count increments/decrements instantly without waiting for network latency.
   - State synchronization keeps card lists and detailed modals perfectly in sync.

4. DYNAMIC FOLDER / GALLERY MANAGEMENT
   - Create custom named gallery folders.
   - Folder visibility settings (Public to Community or Private to Personal).
   - Move images between folder folders instantly using optimized optimistic client-side changes and background synchronization.
   - Folder renaming and safe deletion (assets remain in the library, only their folder association is cleared).
   - Sidebar folder navigation displaying realtime asset counts.

5. SOCIAL METADATA & NESTED COMMENTS
   - Interactive expanded detailed modal for each asset.
   - Full comment pane supporting threaded replies.
   - Displays asset creator handles and profile pictures.

6. SOCIAL NOTIFICATIONS & SYSTEM INTEGRATION
   - Periodic social notification polling (every 15 seconds) with bell dropdown in both Chat (Query Mode) and Library (Image Mode).
   - Specialized notification messages:
     - Like: "[User] liked your image."
     - Top-level Comment: "[User] commented on your image."
     - Nested Reply: "[User] replied to your comment."
     - Asset creation: "[User] created a new image."
   - Click navigation: Clicking a notification automatically redirects the user to the Library page and auto-opens the corresponding image details modal.

7. COMPREHENSIVE FILTERING & SEARCH
   - Realtime prompt search (filters images by prompt terms case-insensitively).
   - Source Filter:
     - All: Shows everything.
     - Personal: Filters down to user-created/uploaded/saved private assets.
     - Community: Filters to public explore/community showcase.
   - Created On Filter: Filter images created "Today", "This Week", or "This Month".
   - Category Filter: Group and filter assets by specific creative domains (e.g. Abstract, Nature, Wildlife, Cyberpunk).

8. CONTEXTUAL IMAGE ACTIONS
   - Share Link: Copy the image link directly to the clipboard.
   - Copy Prompt: Instantly copy the prompt string to paste in the generation composer.
   - Download: Download high-resolution files to the device storage.
   - Delete: Permanently remove user-owned assets from the database.
   - Toggle Visibility: Directly switch assets between Public and Private visibility.

9. HEADER GENERATION SYNC
   - Polling listener syncs active image generation status (`image_gen_status`) from localStorage so generation updates from Chat reflect instantly in the Library header.

AI IMAGE LABS & ASSET LIBRARY API DOCUMENTATION
=========================================================

This section lists the image-related APIs in the backend and explains what each API does.

---

POST /api/v1/features/image/generate
Generates high-fidelity images using text prompts. It also supports image editing and inpainting if a reference base64 image or image URL is supplied in the request body.

POST /api/chat
Used for the AI assistant chatbot. It dynamically executes the image generation tool during the conversation when a user asks for an image, picture, diagram, or other visual aid.

GET /api/v1/library/assets/:id/image
Serves the raw image file directly from the database. It decodes the stored base64 image data and sends it back as a binary image stream with caching headers. If it is an HTTP link, it redirects directly.

GET /api/v1/library/assets
Retrieves all generated image and diagram assets created by the logged-in user.

GET /api/v1/library/public-assets
Retrieves all community-shared public image assets.

GET /api/v1/library/assets/:id
Fetches the detailed metadata, prompt, category, and folder information of a single asset.

PATCH /api/v1/library/assets/:id/visibility
Toggles whether a specific image is public and shared with the community or remains private to the user.

DELETE /api/v1/library/assets/:id
Permanently deletes a specific image asset from the user's library.

PATCH /api/v1/library/assets/:id/category
Updates the category tag of a user's image asset.

POST /api/v1/library/assets/:id/copy-to-library
Copies another user's public image asset into the personal library of the calling user.

POST /api/v1/library/galleries
Creates a new custom folder or gallery to organize image assets.

GET /api/v1/library/galleries
Retrieves a list of all folders and galleries owned by the user, showing the count of images inside each folder.

GET /api/v1/library/public-galleries
Retrieves all public folders and galleries shared by other users.

PATCH /api/v1/library/galleries/:id
Renames a folder/gallery or changes its visibility. Updating folder visibility also updates the visibility of all images inside it.

DELETE /api/v1/library/galleries/:id
Deletes a folder/gallery. The images inside the folder are not deleted; they are simply moved out of the folder.

PATCH /api/v1/library/assets/:id/gallery
Assigns an image asset to a specific folder or gallery.

GET /api/v1/library/public-galleries/:id/assets
Fetches all public images stored inside a specific public shared gallery.

GET /api/v1/library/saved-assets
Fetches all bookmarked/saved images for the user.

POST /api/v1/library/saved-assets/:id/save
Saves/bookmarks a specific image asset.

DELETE /api/v1/library/saved-assets/:id/unsave
Removes a saved/bookmarked image asset.

POST /api/v1/library/assets/:id/like
Likes a public image asset and automatically bookmarks it for the user for 5 days.

DELETE /api/v1/library/assets/:id/unlike
Unlikes a public image asset and removes it from the bookmarks.

GET /api/v1/library/assets/:id/social
Fetches the social interaction data of an image asset, including total likes, liked status of the current user, threaded comments, and the owner's profile info.

POST /api/v1/library/assets/:id/comment
Posts a comment or a reply to an existing comment on an image asset.

GET /api/v1/library/notifications
Retrieves all social notifications for the user, such as when someone likes or comments on their shared images.

POST /api/v1/library/notifications/:id/read
Marks a specific social notification as read.

AI IMAGE LAB - IMAGE EDIT API INTEGRATION GUIDE
=========================================================

To perform image editing (image-to-image) in the AI Image Lab from the web frontend, you need to call the existing Chat API endpoint with a specific payload structure.

1. API Endpoint Details
URL: /api/v1/chat (or /api/v1/features/image/generate)
Method: POST
Headers:
- Content-Type: application/json
- Authorization: Bearer <API_KEY> (or x-api-key: <API_KEY>)
